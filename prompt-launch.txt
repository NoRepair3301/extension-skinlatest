==================== PART A: launch readiness (branch fix/launch-1 from main; tag v0.2.1-rc1; version 0.2.1) ====================
Observed in Edge (rc6): the theme is applied on en.wikipedia.org/wiki/Solar_System; clicking a link to another page of the same site opens it unthemed; after a reload the art and sometimes the theme do not come back. The theme must stay on every page of the site until Restore.

A1. Persistence root cause. Do not guess: read the code, reproduce each suspect with tests on a fake chrome API that replays the exact event order.
a. Edge closes the popup when it shows the permission prompt, which kills any async code the popup was running (registration, saving the record, applying). The popup must do only two things on the click: write a pending intent (origin, tab id, plan, created time, expires in 5 minutes) to storage and call permissions.request as the first awaited call. The background service worker owns everything after that: on permissions.onAdded for that origin it registers the content scripts (applier-auto, scene.js, whatever the site needs), saves the site record, applies to the tab. If the user denies, the reopened popup shows the one-line "this page only" state. Test: the popup "dies" right after the request and registration, record and apply still complete.
b. Reconcile on service-worker start, on install and on update: every site record with permission granted must have its registration with the right files (idempotent); migrate old records (missing fields default safely, add a storage version field).
c. One function turns an origin into a record key and a match pattern (scheme, subdomain, port, IPv6, punycode), used for saving, reading and registering. Tests with awkward origins.
d. The auto script runs at document_start when head and body do not exist. Apply the stored CSS through the adopted stylesheet on the document at once; start guards, repair and art only after DOMContentLoaded; nothing may roll back because a body does not exist yet. Test with a fixture that has no body at script start.
e. Paused state: Restore pauses the site. The popup shows "Paused on this site" with a Resume button; Change my page clears the pause. Test.
f. Full-page and single-page navigations both keep the theme; the observer is bounded and cleaned up on Restore.
A2. "Why not themed here?": the auto script records one short state word for the document (no record, no permission, not registered, paused, applied, rolled back with a reason kind, error kind). The popup shows it as one line with a next step; Copy diagnostics includes it. No origin, URL, text or key in the report. Tests.
