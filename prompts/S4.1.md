# S4.1 — Neutralise gating (Stage 4, F3: everything free)

First substage of removing the paid tiers (T6/F3). This one changes **logic only**: after it, nothing in the app is locked and every theme is available, while UI components and the backend still exist and compile. They are removed in S4.2 (UI), S4.3 (backend) and S4.4 (tests). Keep each step small so `tsc` stays at 0 throughout.

## Session settings
- **Model:** Sonnet 5.5
- **Effort:** high
- **Why:** many call sites across the codebase; each needs the right treatment (delete, simplify or leave for S4.2), and a missed one silently keeps a lock alive.

## Allowed scope
- **Edit (logic):** the module(s) that define `canUse`, `entitledThemes`, the plan-tier clamp helpers and `planFlag`; their non-UI callers (pipeline, settings, api, popup logic that is not a component, commands, keeper, sites); the AI prompt module that lists themes.
- **Tests:** only tests that directly assert the changed functions' behaviour (for example `entitledThemes`, `canUse`, clamp helpers, the AI prompt theme list). Flip lock-related expectations to the free behaviour; never weaken any other assertion. Everything else that fails because of the change (UI, popup, scene, backend tests) stays for S4.2/S4.4: list each such test by name in HANDOFF with the substage that owns it. Aim for zero.
- **Create:** `workflow/PREMIUM_INVENTORY.md`.
- **Session close:** `workflow/PLAN.md`, `workflow/HANDOFF.md`, `workflow/LOG.md`, `workflow/DECISIONS.md`.
- Do not touch: `src/engine/*`, `src/backend/`, `backend/`, UI components (`.tsx` files and their strings: S4.2), `scene.ts`, protected zones, docs, `package.json`, manifest.

## Required behaviour
1. **`canUse`** (or equivalent capability check): make it always true and mark it with a one-line `@deprecated removed in S4.2` comment so UI callers keep compiling. If it has no UI callers at all, delete it instead.
2. **`entitledThemes`** (or equivalent): returns all 6 built-in themes for everyone. The AI prompt's theme list is also all 6 themes, in the same order the app lists them elsewhere.
3. **Clamp helpers** that limit themes, sites, features or counts by plan: reduce to pure pass-through (or delete when unused); no hidden limits remain. Do not change unrelated clamps (numeric UI ranges, contrast, etc.).
4. **`planFlag`**: remove it from every non-UI call site. UI call sites stay for S4.2, and the module stays until then.
5. **No behaviour change outside gating.** Theme application, restore, per-site memory, AI flow and settings behave as before for a user who previously had the highest tier. Storage keys are unchanged (migration is S4.3).
6. Keep each removal evidence-backed: for any symbol you delete, grep shows no remaining reference (apart from ones listed for S4.2/S4.3/S4.4).
