## Step 1 — find and classify
Search `tests/` (case-insensitive) for: `plus|premium|paywall|subscri|checkout|entitle|canUse|planFlag|clampThemeId|clampChoice|clampPlan|free"|"plus"|locked|upgrade|sign.?in|account|supabase|backend|license`. Ignore ordinary uses (`plan` as the theme-plan type, "plus" in math). Append a table to `workflow/TEST_CLASSIFICATION.md` (S4.4 section): file | test | what it protects | verdict | reason. Verdicts:
- **DELETE** — protects only a removed paid-tier feature (evidence: the feature and its code no longer exist; grep).
- **ADAPT** — the behaviour still exists but the test passes plan arguments, asserts locks or "free" fallbacks, or builds Plus fixtures. Rewrite to the free behaviour: no plan argument, all 6 themes valid, nothing clamped.
- **KEEP** — mentions the words but is unrelated; leave untouched.
- **BUG** — a test that reveals a real remaining paid-tier leftover in source. Keep it failing, do not fix `src/`, report with file:line.
A test you cannot classify with evidence is KEEP.

## Step 2 — act
Delete the DELETE tests and any helper/fixture used only by them. Adapt per verdict. Where a clamp or plan argument existed only to be asserted, assert the free behaviour instead (for example "every built-in theme id is accepted and returned unchanged"). Names of adapted tests keep their intent; do not leave a name that still says "free tier" or "Plus".

## Step 3 — add positive tests (T6 coverage)
Add or confirm tests for each of these. Put them in the existing file that already covers the area, or `tests/free-for-all.test.ts` if none fits.
- `T6: all 6 built-in themes are selectable and applicable from the popup logic` (every theme id, no lock state anywhere).

For each new group show one deliberate breakage in a scratch copy (not committed, not in `src/`) that makes it fail, and list in HANDOFF which you verified.
