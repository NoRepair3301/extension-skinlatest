# S4.3 — Remove the backend, premium config and scripts; migration clears old plan data

Third substage of removing the paid tiers (T6/F3). The logic (S4.1) and UI (S4.2) are free of premium. This one deletes the server-side and configuration side: `src/backend/`, the `backend/` folder (Supabase), the entitlement-key script, tsconfig/validate-dist/env/package-script references, and adds a small storage migration so old installs lose their stale auth/entitlement/plan data. Storage key **names** that stay in use do not change (D3).

- **Model:** Sonnet 5.5
- **Effort:** medium
- **Why:** deletions plus config edits with a clear evidence rule; the only design piece is a tiny migration that reuses the project's existing migration mechanism.
