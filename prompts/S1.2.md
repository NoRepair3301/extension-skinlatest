## Why this is being removed (decision D6, one line to record)
The engine enforces contrast per element through `makeTransform` (invariant I10), and `applier-core.ts` already stubs `repairPayload()` and `applyRepair()` (returning nothing), so the AI repair pass can no longer change a page; keeping it would only add a second consent prompt and a provider call with zero effect.
