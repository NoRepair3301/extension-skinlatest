# S4.2 — Remove premium UI; un-gate My assets

Second substage of removing the paid tiers (T6/F3). S4.1 made the logic free. This one deletes everything the user can *see* of the paid tiers (dialogs, account screen, badges, locks, strings, the Options tab) and removes the gate in front of My assets, so the feature works for everyone. The backend, config and storage migration stay for S4.3; remaining tests and docs for S4.4 and S4.5.

- **Effort:** high

- **Delete:** `PlusDialog`, `PlanAccount`, and any component, hook, CSS or asset used only by them (evidence: grep shows no other importer). Delete `planFlag` and the deprecated `canUse` left by S4.1 once their last caller is gone (evidence required).
- **Edit (UI):** `Popup.tsx`, `Options.tsx` and their sub-components, `src/ui/strings.ts` and any other strings file: remove Plus badges, locks, "upgrade" and "sign in/account/plan" buttons, links and copy; remove the plan/account Options tab and make sure tab navigation, default tab and any stored "last tab" value cannot point at a removed tab.
- **Edit (My assets):** remove the premium check in the Options and Popup call sites so My assets works for everyone, and in the protected zone `src/**/scene.ts` (or the scene module the inventory names) touch **only** the one line that gates My assets. No other change in any protected zone (pet, blur, scenes, palette, tables, freespace).

## Required behaviour
1. No user-visible trace of paid tiers remains in popup, options or any page-injected UI: no Plus badge, lock icon, "upgrade", "sign in", "account", "plan", "premium", "subscription" copy. Ordinary uses of the word "plan" for the theme plan or "plus" as ordinary punctuation are not premium; leave them.
2. All 6 themes selectable everywhere; My assets fully usable for every user.
3. Options keeps all its remaining tabs, in the same order, with a valid default; the removed tab leaves no empty gap, dead link or stale route. A stored last-tab value pointing at the removed tab falls back safely (test it).
4. Everything the deleted UI called that is now unused (props, port methods, message types, i18n keys) is removed only if grep proves it unused; backend-facing API calls stay for S4.3.
5. No behaviour change outside the premium surface. Per-site memory, restore, AI flow, pets, blur, scenes and palette behave as before.
