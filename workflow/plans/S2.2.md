## Steps
1. Refresh keeps the element's record instead of dropping and rebuilding it (`reset()` is now only for restore()):
   `lift(el)` per recorded prop: own write still in place -> put back `o/p` temporarily so the computed style shows the page's value;
   page changed it -> re-base `o,p := current` (I5). Then compute, re-write via `put()` (existing entries keep the re-based `o/p`),
   and drop entries the new pass no longer writes. A record left with no props is released (marker off, I6 attribute rule,
   original text carried as today).
2. Transition suppression goes through the ledger (I2): `suppressTransition` writes `transition: none !important` via `put()`;
   `restoreTransitions` undoes it with the same guard as reset (a page change to `transition` wins) and releases empty records.
   Fixes the S2.1 bug: stylesheet-themed element refreshed, then restored, no longer ends with `style=""` (I6).
3. No feedback loops (I7): every engine write stays inside `quiet()`; tests prove a refresh settles (no further style
   mutations, no re-queue) and restore leaves nothing pending.
